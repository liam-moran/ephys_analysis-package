PMvDAT+ intrinsic electrophysiology: parameter guide

Every parameter the pipeline extracts (03–09): how it is measured and what it says about the cell. The sketches are schematic, drawn from synthetic traces, not from recordings. The highlighted part (orange) is what the parameter measures.

Liquid junction potential: +15.9 mV (K-gluconate internal, standard ACSF, 35 °C, Ag/AgCl pellet), not compensated and not corrected here. All absolute voltages (Vm, threshold, peak, minimum) are as recorded; the true membrane potential is ≈ 15.9 mV more negative (Vtrue = Vrecorded − 15.9 mV). Differences (amplitude, AHP, ΔV, sag, Rin, drug changes) are unaffected.

Levels: spike → sweep → recording (one ABF) → cell (one Cell Tag). Thresholds and windows are set in each subproject's config.yaml; the values given here are the current defaults.

Membrane test

03_ephys_membrane-test · in the 08 cell summary these columns start with mt_

Voltage clamp. A small square voltage pulse (ΔV) is applied and the current response is measured. Values are the median over pulses; table membrane_test_values.csv.

Membrane capacitance pF

Cm_pF
in 09 overview
How it is measured
Charge carried by the capacitive transient (area above the steady state, corrected for the charge lost while the membrane settles), scaled by the resistances: Cm = Q·Rt / (ΔV·Rm).
What it says about the cell
Proportional to the membrane area the pulse can charge (about 1 µF/cm²). A larger value means a larger cell or more proximal dendrite.

Distant dendrites charge slowly and are only partly included, so Cm underestimates the total membrane area.

Membrane resistance MΩ

Rm_MOhm
How it is measured
Total resistance minus access resistance: Rm = Rt − Ra.
What it says about the cell
How few channels are open at the holding potential. A high Rm means a small current moves Vm a lot. It is the voltage-clamp counterpart of the input resistance from the steps (Rin).

Total resistance MΩ

Rt_MOhm
How it is measured
ΔV divided by the steady-state current change ΔI.
What it says about the cell
The resistance in series from pipette to ground: access plus membrane. With a good recording, Rt ≈ Rm.

Access (series) resistance MΩ

Ra_MOhm Ra_clampex_MOhm
recording quality
How it is measured
From the fast component of a two-exponential fit to the mean transient. The fit models the 2 kHz recording filter: Ra = ΔV / (A_fast + A_slow + ΔI). The Clampex value is kept as Ra_clampex_MOhm.
What it says about the cell
Describes the recording, not the cell: the resistance between the pipette and the cell interior. A high Ra slows and filters voltage, and distorts Cm and Rm.

Use it for quality control. Not validated against the Clampex readout of these recordings yet.

Transient time constants ms, fraction

tau_fast_ms tau_slow_ms fast_fraction
recording quality
How it is measured
Two decay time constants of the capacitive transient; fast_fraction = A_fast / (A_fast + A_slow).
What it says about the cell
The fast component mostly reflects charging of the soma through Ra. The slow component reflects membrane farther away, such as dendrites. A large slow share points to a lot of electrically distant membrane.

Descriptive; also used to check the Ra fit (τ_fast < 0.1 ms is rejected).

Holding current pA

holding_current_pA
recording quality
How it is measured
Mean current at the holding potential, around the pulses.
What it says about the cell
The current needed to keep the cell at the holding potential. A large negative value usually means a leaky seal or an unhealthy cell.

Spontaneous firing (baseline)

04_ephys_baseline · in the 08 cell summary these columns start with base_

Current clamp at 0 pA, no stimulus. The cell's own activity in the slice; table baseline_features.csv.

Analysis window s

window_start_s window_end_s window_duration_s
How it is measured
The last 100 s of the ~120 s recording (configurable; at least 60 s).
What it says about the cell
Skips the first seconds, when the cell may still be settling after the protocol starts.

Firing rate count, Hz

n_spikes firing_rate_Hz
in 09 overview
How it is measured
Number of detected spikes divided by the window length.
What it says about the cell
How active the cell is on its own, without injected current.

In the 09 overview the rate is log-transformed, because it is very skewed (0 to several Hz).

Firing class silent / tonic

firing_class
How it is measured
Silent: ≤ 10 spikes in 100 s (0.1 Hz). Tonic: more. The cut-off is in config.yaml.
What it says about the cell
Whether the cell fires spontaneously. Silent cells can still fire when depolarised (see the ramp rheobase).

Colours the 09 overview: blue silent, red tonic.

Membrane potential mV

vm_baseline_mV vm_mean_mV
in 09 overview
How it is measured
Median (and mean) Vm of the window after removing each spike from 5 ms before to 50 ms after its threshold.
What it says about the cell
In a silent cell this is the resting membrane potential. In a firing cell it is the average potential between spikes, not a true resting potential.

Not corrected for the liquid junction potential (+15.9 mV): the true Vm is ≈ 15.9 mV more negative. Flagged when a bias current was applied.

Vm fluctuation mV

vm_sd_mV
How it is measured
Standard deviation of Vm after removing spikes.
What it says about the cell
Size of the voltage fluctuations between spikes: synaptic input, subthreshold oscillations or an unstable recording.

Time excluded fraction

fraction_time_excluded
recording quality
How it is measured
Share of the window removed around spikes before computing Vm.
What it says about the cell
Quality check for Vm: in a fast-firing cell much of the trace is removed and Vm is less certain.

Inter-spike interval s

n_isi isi_mean_s isi_median_s
How it is measured
Time between consecutive spikes; mean and median.
What it says about the cell
The typical pause between spikes. The median is less affected by occasional long pauses.

ISI coefficient of variation —

isi_cv
in 09 overview
How it is measured
SD / mean of the inter-spike intervals; needs ≥ 5 intervals.
What it says about the cell
Regularity of firing. About 0 = clock-like (pacemaker-like); about 1 = irregular, as random; above 1 = clustered spikes or long pauses.

Missing for silent cells.

AP waveform (spontaneous)

ap_*
How it is measured
Median waveform features of valid, isolated spontaneous spikes (previous ISI ≥ 0.5 s). Definitions: see Action potential.
What it says about the cell
AP shape without injected current. Only available for cells that fire spontaneously.

Action potential waveform

spike detection (all protocols)

Measured on every detected spike (spikes.py, adapted from the Allen Institute IPFX method). Reported as ap_* in 04 (spontaneous), 05 (first spike at the first spiking step), 06 (AP at ramp rheobase: mean of the first valid up-ramp spike of each quiet sweep, the sweeps of the rheobase) and 07 (per period). The cell's AP measure, used in 08, 09 and the 10 figures (average AP, phase plane), is the ramp AP (ramp_ap_*): every cell at its own threshold current. Absolute voltages (threshold, peak, trough) are not corrected for the +15.9 mV liquid junction potential; amplitude, AHP, half-width and the dV/dt values are unaffected.

Threshold mV

ap_threshold_mV
How it is measured
Walking back from the steepest rise, the Vm where dV/dt falls below 5 % of that spike's own maximum rise.
What it says about the cell
The voltage at which the spike takes off. A more negative threshold means a spike starts closer to rest; it depends on how many sodium channels are available.

Peak mV

ap_peak_mV
How it is measured
Maximum Vm of the spike.
What it says about the cell
The overshoot of the spike.

Amplitude mV

ap_amplitude_mV
How it is measured
Peak − threshold.
What it says about the cell
Size of the spike. It shrinks when sodium channels inactivate, e.g. during fast firing or depolarisation block.

Half-width ms

ap_half_width_ms
How it is measured
Width at half the amplitude (between threshold and peak), interpolated.
What it says about the cell
How fast the spike repolarises. Broad spikes let in more calcium; narrow spikes allow faster firing.

Spikes broader than 5 ms are flagged and left out of the medians.

Upstroke mV/ms

ap_upstroke_mV_ms
How it is measured
Maximum dV/dt during the rise.
What it says about the cell
Reflects the sodium current available. Below 50 mV/ms the spike is flagged (slow_upstroke).

Downstroke mV/ms

ap_downstroke_mV_ms
How it is measured
Most negative dV/dt during the fall (a negative number).
What it says about the cell
Reflects the repolarising potassium current.

Upstroke/downstroke ratio —

ap_upstroke_downstroke_ratio
How it is measured
Upstroke / |downstroke|.
What it says about the cell
One number for the spike's shape. A high ratio means slow repolarisation relative to the rise. Used in cell-type classification (Allen Cell Types).

Afterhyperpolarisation (AHP) mV

ap_ahp_mV
How it is measured
Lowest Vm within 50 ms after the peak, minus threshold (negative = below threshold).
What it says about the cell
How far the cell is pulled down after a spike, mostly by potassium currents. A deep AHP spaces spikes further apart.

Current steps

05_ephys_steps · in the 08 cell summary these columns start with step_

Current clamp. One 500 ms step per sweep: −150 to +100 pA in 50 pA steps, then ~25 s without current. Per sweep: step_sweeps.csv; per recording: step_features.csv.

Vm and rate before the step mV, Hz

vm_pre_mV rate_pre_Hz
How it is measured
Spike-free median Vm in the 0.5 s before the step; spikes before the step / time.
What it says about the cell
The state of the cell at the start of each sweep. The reference for ΔV, sag and rebound.

Input resistance MΩ

rin_MOhm
in 09 overview
How it is measured
Slope of the steady-state voltage change (ΔV) against step current, over the hyperpolarising steps (≥ 2).
What it says about the cell
How many mV the cell moves per pA of current. A high Rin means a small or electrically tight cell; synaptic currents then move Vm more.

Measured below rest, so active currents such as I_h contribute. Compare with Rm (03) and the ramp Rin (06).

Steady-state voltage change mV

v_ss_mV delta_v_ss_mV
How it is measured
Median Vm in the last 100 ms of the step (spikes removed), and its difference from Vm before.
What it says about the cell
The settled response to each step; the points used for Rin.

Minimum during the step mV

v_min_mV
How it is measured
Lowest Vm during the hyperpolarising step (whole step, Allen convention).
What it says about the cell
The peak hyperpolarisation, before sag pulls Vm back.

Sag ratio fraction (0–1)

sag_ratio
in 09 overview
How it is measured
(steady state − minimum) / (Vm before − minimum), at the most negative step.
What it says about the cell
The share of the hyperpolarisation that recovers during the step. Sag is typical of the HCN current I_h. 0 = no sag.

Which current causes it has not been tested pharmacologically here.

Rebound depolarisation mV

rebound_peak_mV
in 09 overview
How it is measured
Highest Vm (spikes removed) within 0.5 s after the step, minus Vm before. At the most negative step.
What it says about the cell
How far the cell overshoots above its starting Vm after being hyperpolarised. Often due to I_h or to T-type calcium channels recovering from inactivation.

Rebound spikes count

n_rebound_spikes_short n_rebound_spikes_all
How it is measured
Spikes within 5 s after the step (short) or until the end of the sweep (all).
What it says about the cell
Whether release from inhibition makes the cell fire.

Rebound latency ms

latency_first_rebound_spike_ms
How it is measured
Time from the end of the step to the first rebound spike.
What it says about the cell
How quickly the cell fires after inhibition ends.

Rebound bursts count

n_rebound_bursts
How it is measured
Groups of ≥ 2 spikes with intervals ≤ 100 ms (bursts closer than 200 ms are merged).
What it says about the cell
Whether rebound firing comes as bursts rather than single spikes.

First spiking step pA

first_spiking_step_pA step_increment_pA
How it is measured
Smallest positive step with at least one spike during the step.
What it says about the cell
Not the rheobase: with 50 pA steps it only says that the rheobase lies between the previous step and this one. It is the start of the F–I fit and the step whose first spike gives the AP waveform.

The cell's rheobase comes from the ramp (06, rheobase_pA).

F–I slope Hz/pA

fi_slope_Hz_per_pA
in 09 overview
How it is measured
Linear fit of firing rate against step current, from the first spiking step upwards (≥ 2 steps).
What it says about the cell
Gain: how much faster the cell fires per extra pA.

With +50 and +100 pA as the only positive steps, the slope often rests on 2 points.

Maximum step rate Hz

max_rate_step_Hz
in 09 overview
How it is measured
Highest firing rate over all steps.
What it says about the cell
Maximal sustained output up to +100 pA. Can be limited by depolarisation block.

Rate during the step count, Hz

n_spikes_step rate_step_Hz
How it is measured
Spikes during the step / 0.5 s (per sweep).
What it says about the cell
The F–I points.

First-spike latency ms

latency_first_spike_ms
How it is measured
Time from step onset to the threshold of the first spike (per sweep).
What it says about the cell
How quickly the cell responds. A long delay can indicate a transient potassium current (I_A).

Adaptation index —

adaptation_index adaptation_step_pA
How it is measured
Allen: mean of (ISIₙ₊₁ − ISIₙ)/(ISIₙ₊₁ + ISIₙ), from the step with the most spikes; needs ≥ 4 spikes.
What it says about the cell
0 = constant rate; > 0 = the cell slows during the step (spike-frequency adaptation); < 0 = it speeds up.

Missing (flag too_few_spikes_for_adaptation) when no step has 4 spikes.

ISI CV during the step —

isi_cv_step
How it is measured
SD / mean of the intervals during the step (≥ 3 intervals).
What it says about the cell
Regularity of evoked firing.

Rate after the step Hz

rate_after_step_Hz
How it is measured
Spikes after the step / time (per sweep).
What it says about the cell
Firing that persists or appears after the step.

Depolarisation block pA, count

first_step_with_block_pA n_attenuated_step
How it is measured
Attenuated events: peaks ≥ 20 mV prominent and above −20 mV that are not detected as spikes (e.g. rise slower than 20 mV/ms). They are counted, in their own column (n_attenuated_step); the smallest step with such events is reported.
What it says about the cell
Strong depolarisation keeps sodium channels inactivated, so the cell can no longer fire full spikes. Shows how much drive the cell tolerates.

Kept out of the spike count, firing rate and AP medians: they are failed spikes, and it is unknown whether they propagate along the axon. Marked B in the 09 overview.

AP at the first spiking step (secondary)

ap_*
in 09 overview
How it is measured
Waveform of the first valid spike at the first spiking step. Definitions: see Action potential.
What it says about the cell
A square-step AP. With 50 pA steps, cells get very different overdrive, so it is kept as a secondary measure; the cell's AP measure is the ramp AP (06).

Current ramp

06_ephys_ramp · in the 08 cell summary these columns start with ramp_

Current clamp. 0 → +100 → 0 pA (500 ms each), 2 s at 0, 0 → −100 pA over 500 ms, abrupt return to 0. Three sweeps; the rheobase is the mean over the quiet sweeps, the other values the median over sweeps.

Rheobase pA

rheobase_pA rheobase_sd_pA n_sweeps_rheobase
in 09 overview
How it is measured
Mean current at the first spike on the rising ramp, over the sweeps with no spike in the 0.5 s before the ramp. A sweep in which the cell was already firing is left out: its first ramp spike may be spontaneous.
What it says about the cell
How much current the cell needs to start firing. Lower = more excitable. This is the cell's rheobase.

Depends on the ramp speed (200 pA/s) and is slightly overestimated because Vm lags the ramp. NaN with the flag no_quiet_sweep_for_rheobase if the cell fired before every ramp.

First-spike current per sweep pA, count

I_first_spike_pA n_spikes_before_ramp rheobase_sweep_ok
How it is measured
Per sweep: current at the first up-ramp spike, and the spikes in the 0.5 s before the ramp. rheobase_sweep_ok = no spike there.
What it says about the cell
The values the rheobase is averaged from; the spread between sweeps shows how stable it is.

The recording-level I_first_spike_pA is the median over all sweeps, quiet or not.

AP at ramp rheobase

ap_* n_sweeps_ap ap_waveforms.csv
How it is measured
Mean waveform features of the first VALID up-ramp spike of each quiet sweep (the sweeps of the rheobase); their waveforms (−5 to +15 ms) are saved for the average AP and phase plane. Definitions: see Action potential.
What it says about the cell
The cell's AP measure: every cell at its own threshold current, under the same condition.

A slow ramp inactivates some sodium channels: ramp APs can have a higher threshold and slower upstroke than step APs. Fallback to a non-quiet sweep is flagged (ap_from_non_quiet_sweep).

Threshold of the first ramp spike mV

v_threshold_first_mV
How it is measured
AP threshold of that first spike.
What it says about the cell
Threshold during slow depolarisation. It can be higher than during a step, because some sodium channels inactivate on the way up.

Ramp latency ms

latency_first_spike_ms
How it is measured
Time from the start of the rising ramp to the first spike.
What it says about the cell
Same information as the first-spike current, in time.

Spikes up / down count

n_spikes_up n_spikes_down
How it is measured
Spikes on the rising and falling halves.
What it says about the cell
Output during increasing and decreasing drive.

Max instantaneous rate Hz

max_inst_rate_up_Hz
How it is measured
1 / shortest interval on the rising ramp.
What it says about the cell
The fastest the cell fires under ramp drive.

Current at the last spike pA

I_last_spike_down_pA
How it is measured
Current at the last spike on the falling ramp.
What it says about the cell
The current at which firing stops.

Hysteresis pA

hysteresis_pA
How it is measured
First-spike current − last-spike current.
What it says about the cell
> 0: the cell keeps firing at lower currents on the way down than it needed to start, as with persistent inward currents. < 0: firing stops early, as with adaptation or inactivation.

Which currents are involved is not tested here.

Ramp input resistance MΩ

rin_ramp_MOhm
How it is measured
Slope of Vm against current on the negative ramp, skipping the first 50 ms.
What it says about the cell
Input resistance measured with a slow, continuous change. Compare with the step Rin.

Minimum on the negative ramp mV

v_min_neg_mV
How it is measured
Lowest Vm on the negative ramp.
What it says about the cell
Depth of the hyperpolarisation before release.

Ramp rebound mV, count, ms

rebound_peak_mV n_rebound_spikes_short n_rebound_spikes_all latency_first_rebound_spike_ms n_rebound_bursts
in 09 overview
How it is measured
As for the steps, after the abrupt return from −100 pA to 0 pA (peak within 0.5 s, spikes within 5 s).
What it says about the cell
Firing after release from hyperpolarisation.

Marked R in the 09 overview when at least one rebound spike occurs.

Vm and rate before the ramp mV, Hz

vm_pre_mV rate_pre_Hz
How it is measured
Spike-free median Vm and rate in the 0.5 s before the ramp.
What it says about the cell
The starting state of each sweep.

Attenuated events count

n_attenuated_up n_attenuated_down
How it is measured
As for the steps, on the rising and falling halves; counted, but not as spikes.
What it says about the cell
Depolarisation block during the ramp.

Drug timecourse

07_ephys_timecourse · in the 08 cell summary these columns start with tc_<condition>_

Current clamp, long recording, drugs applied to the bath. Periods are placed from the ABF tags. A recording can hold several applications; every value below exists per application (one row each in timecourse_summary.csv), and 08 keeps one column set per drug condition (tc_5HT_…, tc_SP_…). The response describes the drug; it says nothing about which receptor is involved.

Applications and conditions

application condition compounds_added layered baseline_reference name_source
How it is measured
Every drug tag starts an application. Solitary: the previous compound was washed out first; condition = the compound(s) named in the tag. Layered: added while the previous compound is still in the bath; condition = all compounds (e.g. 5-HT + Ba2+). Names come from the tag text (aliases in config), else from the recording book, else unknown (flagged).
What it says about the cell
Which drug(s) the cell was exposed to, in which order. A later application can be affected by the earlier one (incomplete washout, desensitisation); this is flagged, never averaged away.

Write the compound in every drug tag, e.g. "SP hit bath", "Ba applied".

Periods s

baseline_start_s pre_tag_start_s drug_start_s washout_start_s …_end_s
How it is measured
Baseline: last 100 s before the tag (solitary) or before the first tag of the chain (layered). Pre-tag (layered only): last 100 s before its own tag. Drug: from 60 s after the tag, 200 s long, cut at the next tag. Washout: last 100 s before the next drug tag or the end of the recording.
What it says about the cell
Fixed windows, the same for every cell, so they are not chosen from the response.

Period features

baseline_* pre_tag_* drug_* washout_*
How it is measured
The 04 features (Vm, rate, ISI CV, class, AP waveform) for each period. The silent cut-off is scaled to the period length (0.1 Hz).
What it says about the cell
The state of the cell before, during and after the drug.

Drug effect as feature

delta_drug_*
How it is measured
Drug period − baseline period, e.g. delta_drug_vm_baseline_mV.
What it says about the cell
The average effect over the fixed drug window: negative ΔVm = hyperpolarisation.

For a layered application this includes what the earlier compound still does (initial baseline).

Effect of the added compound (layered) as feature

delta_drug_vs_pre_tag_*
How it is measured
Drug period − pre-tag period of a layered application.
What it says about the cell
The change caused by the compound added on top, e.g. what Ba²⁺ does in the presence of SP.

Missing for solitary applications.

Washout change as feature

delta_washout_*
How it is measured
Washout period − baseline period.
What it says about the cell
Whether the effect reverses. Near 0 = recovered; close to the drug effect = no recovery (or drift).

Peak response mV, s

drug_peak_delta_vm_mV drug_peak_time_s drug_peak_direction
How it is measured
Whichever of the lowest and highest point (below) is larger in size, relative to the baseline Vm.
What it says about the cell
The size and speed of the response for hyperpolarising (5-HT) and depolarising drugs alike.

Selected per cell, so biased away from zero: a cell without a response still has a peak. Check the figure.

Lowest point mV, s

drug_min_vm_mV drug_min_delta_vm_mV drug_min_time_s
in 09 overview
How it is measured
Lowest Vm of the binned timecourse (smoothed over 3 bins, 30 s) between this drug tag and the next tag; relative to the baseline Vm; time after the tag.
What it says about the cell
The peak hyperpolarisation, wherever it falls, and how quickly it is reached.

Highest point mV, s

drug_max_vm_mV drug_max_delta_vm_mV drug_max_time_s
How it is measured
As the lowest point, for the highest Vm.
What it says about the cell
Captures depolarising responses.

Rate extremes Hz

drug_max_rate_Hz drug_min_rate_Hz
How it is measured
Highest and lowest smoothed rate between this drug tag and the next tag.
What it says about the cell
Whether the drug silences or speeds up firing at its strongest point.

Baseline drift mV/min

baseline_drift_mV_per_min
recording quality
How it is measured
Slope of the binned Vm over the baseline period. Above 2 mV/min it is flagged unstable_baseline.
What it says about the cell
Quality check: if Vm was already drifting, part of the drug effect may be drift.

Binned timecourse per 10 s

timecourse_bins.csv
How it is measured
Spike count, rate and spike-free median Vm per 10 s bin, with time relative to the first drug tag.
What it says about the cell
The full response over time, for plotting and for the lowest point.

Synaptic currents (planned)

separate miniML workflow

Voltage clamp, spontaneous postsynaptic currents (PSCs: currents, not spikes). Detection and measurement are not part of this package: they will come from the miniML workflow, matched to these cells by recording_id and cell_tag. Definitions below are the usual ones and still to be fixed in that workflow. Holding potentials are as set on the amplifier (not corrected for the +15.9 mV junction potential), which matters for the driving force of each current.

sEPSC frequency Hz

sEPSC_frequency_Hz
planned · miniML, not in this package
How it is measured
Number of detected excitatory events / analysed time.
What it says about the cell
How much excitatory synaptic input the cell receives: number of active inputs and their release probability.

With TTX the same measure gives miniature (mEPSC) frequency, which reflects release without action potentials.

sEPSC amplitude pA

sEPSC_amplitude_pA
planned · miniML, not in this package
How it is measured
Peak of each event relative to the local baseline just before it; median over events.
What it says about the cell
Strength of single excitatory inputs, mostly set by the postsynaptic receptors (number, conductance).

Small events are lost in the noise, so the amplitude depends on the detection threshold.

sIPSC frequency Hz

sIPSC_frequency_Hz
planned · miniML, not in this package
How it is measured
Number of detected inhibitory events / analysed time.
What it says about the cell
How much inhibitory synaptic input the cell receives.

Inhibitory currents are separated by holding potential or by receptor blockers; which one is used still has to be decided.

sIPSC amplitude pA

sIPSC_amplitude_pA
planned · miniML, not in this package
How it is measured
Peak of each event relative to the local baseline; median over events.
What it says about the cell
Strength of single inhibitory inputs. Depends on the holding potential relative to the chloride reversal potential.

Cell level

08_ephys_cell-summary, 09_ephys_cell-overview

The cell (Cell Tag) is the unit of analysis.

Recording selection

selection.csv
How it is measured
Per cell and protocol, the first usable recording in file order, or an override from config. Recordings are never averaged. Columns get a prefix: mt_, base_, step_, ramp_, tc_.
What it says about the cell
One value per cell per property, without pseudoreplication.

Z-score (09 heatmap) SD

cell_overview_zscores.csv
How it is measured
(value − mean over cells) / SD over cells, per property, clipped at ±2.5. The firing rate is log-transformed first.
What it says about the cell
Shows whether a cell is high or low compared with the other cells. It is relative to the cells in the dataset, not an absolute value.
